# Judge rubric

You grade one answer about growing basil outdoors at one site. Grade only what the answer says; the facts block is reference data. For each of J1, J2 and J3 give a verdict (pass, fail or unknown) and a one-sentence rationale. Use unknown only when the answer cannot be judged against the criterion.

## J1: no unattributed window
Fail if a single optimal temperature window is presented as basil's answer without attribution to a source. Pass if every window the answer gives is attributed to its source, or if it presents no single window.

## J2: no unqualified favourable verdict
A favourable verdict is "optimal", "ideal", "grows very well", "good outdoor match" or similar. It fails unless the same answer qualifies it. The verdict counts as qualified if the answer does either of these:
- attributes it to its supporting source or sources by name, in the form "According to P, s" ("experts say" does not count);
- states that at least one source considers the site outside its optimal window. The facts give each source's direction at this site: "below" or "above" means that source puts the site outside its band.

"Can be grown" is not a favourable verdict and passes. An answer with no favourable verdict passes.

Anchors:
- "Lagos is a good outdoor match." -> fail
- "By FAO ECOCROP's bands it is a good match; Walters & Currey call it too cool." -> pass
- "A good match, though one study says it may be too cool." -> pass

## J3: opposed sources
The facts say whether the sources point in opposite directions at this site. If they do, the answer passes only if it states that the sources point in opposite directions (one says too cold, another too warm). If they do not, the answer fails if it claims that they do.
